# فروشگاه و جریان خرید

کاتالوگ، جست‌وجو و کارت‌ها را از صفحهٔ جزئیات و قرارداد سبد جدا بررسی کنید. کاتالوگ و طرح فروش از SQL خوانده می‌شوند؛ state حساب و سفارش از API حساب می‌آید. بخشی از رکوردهای اولیه نمونه‌اند و پرداخت/فروش نهایی هنوز به درگاه و تأیید انبار وصل نیست.

| راهنما | موضوع |
|---|---|
| [کاتالوگ و فهرست‌ها](catalog.md) | مدل محصول، رنگ، کشور، خانه، Search و مقایسه |
| [جزئیات محصول](product.md) | رندر دیتیل، رسانه، ویژگی، feedback و افزودن به سبد |
| [سبد و تسویه](cart.md) | قرارداد واحد HNUI.cart، گزینه‌ها، مبلغ و آدرس |
| [پرداخت سفارش](payment.md) | قرارداد هستهٔ پرداخت، صف انبار و جای اتصال درگاه |
| [فروش چندطرحی](sales-plans.md) | طرح پیش‌فرض و ویژه، offer مستقل، snapshot قیمت و فاصله تا اتصال runtime |
| [فهرست درگاه‌های پرداخت](payment-institutions.md) | نام‌های عمومی درگاه‌ها و محل نمایش |

راهنمای تازهٔ این حوزه را در همین پوشه ایجاد و در این جدول ثبت کنید؛ جزئیات در [قانون مستندسازی](../development/documentation.md).
