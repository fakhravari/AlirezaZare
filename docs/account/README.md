# حساب کاربری

پروفایل، نشست، نشانی و تعاملات حساب در این بخش مستند می‌شوند. پنل بازشوندهٔ حساب در هدر فروشگاه، مالک UI مشترک دارد و در [راهنمای frontend](../frontend/layout.md) دنبال می‌شود.

| راهنما | مسئولیت |
|---|---|
| [پروفایل](profile.md) | احراز هویت، اطلاعات شخصی، نشانی‌ها، سفارش‌ها و دادهٔ حساب |

پیش از تغییر، routeها را در `Shop/Controllers/AccountController.cs` و `ProfileController.cs` و source داده را از DI دنبال کنید. [فهرست docs](../README.md).
