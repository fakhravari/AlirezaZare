# حساب کاربری

این بخش مالک ثبت‌نام و تأیید ایمیل، پروفایل، آدرس و سفارش‌های نمایشی کاربر است. تأیید OTP در backend انجام می‌شود اما ایجاد حساب و session هنوز دمو هستند؛ جزئیات در راهنمای پروفایل و مرز backend ثبت شده‌اند. پنل حساب هدر جزو رابط مشترک است.

| راهنما | موضوع |
|---|---|
| [پروفایل و زیرصفحه‌ها](profile.md) | route مشترک، فرم ورود و ثبت‌نام، تأیید ایمیل، ویرایش پروفایل، آدرس، سفارش و state محلی |

راهنمای تازهٔ این حوزه را در همین پوشه ایجاد و در این جدول ثبت کنید؛ جزئیات در [قانون مستندسازی](../development/documentation.md).
