# حساب کاربری

این بخش مالک ثبت‌نام و تأیید ایمیل، پروفایل، آدرس و سفارش‌های حساب است. OTP، ایجاد پروفایل، نشست cookie و داده‌های کاربر به API و دیتابیس متصل‌اند؛ سفارش‌های seed نمایشی‌اند و اتصال درگاه پرداخت واقعی و جریان انبار پس از پرداخت باقی مانده است. جزئیات در راهنمای پروفایل و مرز backend ثبت شده‌اند. پنل حساب هدر جزو رابط مشترک است.

| راهنما | موضوع |
|---|---|
| [پروفایل و زیرصفحه‌ها](profile.md) | route مشترک، فرم ورود و ثبت‌نام، تأیید ایمیل، ویرایش پروفایل، آدرس، سفارش و اتصال API حساب |

راهنمای تازهٔ این حوزه را در همین پوشه ایجاد و در این جدول ثبت کنید؛ جزئیات در [قانون مستندسازی](../development/documentation.md).
