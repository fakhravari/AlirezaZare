# رابط کاربری

از layout برای ترتیب فایل‌های مشترک شروع کنید؛ برای قابلیت‌های خاص، راهنمای حوزه (فروشگاه، حساب یا مدیریت) مرجع است.

| راهنما | استفاده |
|---|---|
| [پوسته و بارگذاری](layout.md) | Razor layout و CSS/JS مشترک |
| [CSS](styling.md) | توکن، selector و مالکیت stylesheet |
| [JavaScript](javascript.md) | HNUI، API، event و state مرورگر |
| [بازبینی UI](verification.md) | روش بررسی رفتار، دسترس‌پذیری و responsive |
| [دفترچهٔ مالکیت UI](ui-ownership-roadmap.md) | ثبت پیشرفت کار چندمرحله‌ای مالکیت |

پیش از تغییر مالک فایل را در `tools/ui-owners.json` ببینید. فهرست اصلی: [docs](../README.md).
