# بررسی رابط کاربری

این چک‌لیست برای تغییر UI فروشگاه است؛ بررسی پنل مدیریت را با layout و owner خود Admin انجام دهید.

## مسیر بررسی

1. markup و route صفحه را در [نقشهٔ مسیرها](../architecture/routing.md) پیدا کنید.
2. owner را در `tools/ui-owners.json` ببینید و ترتیب بارگذاری را از [layout](layout.md) تأیید کنید.
3. رفتار پایه، خالی، بارگذاری، خطا و موفقیت را بررسی کنید.
4. عرض باریک موبایل، تبلت و دسکتاپ را با RTL کنترل کنید؛ horizontal overflow ناخواسته، focus، نام accessible و reduced motion را بررسی کنید.
5. Console/Network را برای خطای JS/API ببینید و نتیجه را از ظاهر جدا گزارش کنید.

برای تغییر shared، یک صفحهٔ مصرف‌کنندهٔ دیگر هم مرور کنید. مرور بصری به‌تنهایی اثبات API یا ذخیرهٔ داده نیست. کنترل‌های خودکار در [کیفیت](../development/quality.md) است؛ فرامین اسکریپت را از `package.json` بخوانید.
