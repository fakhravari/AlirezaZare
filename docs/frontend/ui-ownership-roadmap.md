# دفترچهٔ مالکیت UI

این دفترچه فقط برای کار چندمرحله‌ای روی تفکیک یا انتقال مالکیت رابط است. نقشهٔ منبع حقیقت مالک‌ها، `tools/ui-owners.json` است؛ فهرست پروژه‌ای و قدیمی در این سند ایجاد نکنید.

## قالب ثبت کار فعال

هنگام آغاز کار چندمرحله‌ای ثبت کنید:

- **حوزه/owner:**
- **وضعیت و درصد:**
- **تغییرهای تکمیل‌شده و شاهد:**
- **فایل‌های باقی‌مانده:**
- **گام بعدی دقیق:**
- **محدودیت/فرمان اجرا‌نشده:**

پس از هر گام این موارد را به‌روز کنید. اگر کار فعالی وجود ندارد، این دفترچه را خالی از وضعیت ساختگی نگه دارید؛ مالکیت جاری را از JSON بخوانید.

## آغاز بررسی

۱. `tools/ui-owners.json` را بخوانید؛ ۲. مسیر markup/CSS/JS واقعی را بررسی کنید؛ ۳. `node tools/check-ui.mjs` اجرا کنید؛ ۴. مرور بصری و نتیجه را ثبت کنید.
