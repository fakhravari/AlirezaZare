# محتوا و صفحه‌های عمومی

بخش مجلهٔ صفحهٔ اصلی همان قالب شاخص/فهرست راهنماها را با کلاس‌های `journal-main` و `journal-list` حفظ می‌کند و مقاله‌های منتشرشده را از منبع دیتابیس مجله نمایش می‌دهد.

صفحه‌های تحریریه و خدمات در این بخش‌اند؛ SEO و metadata در [بخش SEO](../seo/README.md) مالک جدا دارند.

| راهنما | مسئولیت |
|---|---|
| [صفحه‌های محتوا](pages.md) | مقاله، برند، FAQ، قوانین و صفحه‌های خدمات |

برای صفحهٔ خاص از controller و View مستقیم شروع کنید؛ داده‌های DB را با seed و متن ثابت Razor تفکیک کنید. [فهرست docs](../README.md).
