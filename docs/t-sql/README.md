# نمونه‌های T-SQL

این پوشه queryهای کمکی برای بررسی داده‌های زندهٔ فروشگاه را نگه می‌دارد. نمونه‌ها فقط خواندنی‌اند مگر آن‌که در متن query خلاف آن مشخص شده باشد؛ پیش از اجرا، شناسه‌ها و نام ستون‌ها را با نسخهٔ جاری پایگاه تطبیق دهید.

| نمونه | کاربرد |
|---|---|
| [سبد خرید](سبد%20خرید.sql) | نمایش سطری اقلام، ویژگی‌ها و متعلقات سبد همراه با قیمت پایه، تخفیف و مبلغ نهایی |

این query برای گزارش و عیب‌یابی است؛ محاسبه و ثبت نهایی مبلغ سفارش را API سمت سرور انجام می‌دهد. [راهنمای سبد](../store/cart.md)
