# نمونه‌های T-SQL

این پوشه queryهای کمکی برای بررسی داده‌های زندهٔ فروشگاه را نگه می‌دارد. نمونه‌ها فقط خواندنی‌اند مگر آن‌که در متن query خلاف آن مشخص شده باشد؛ پیش از اجرا، شناسه‌ها و نام ستون‌ها را با نسخهٔ جاری پایگاه تطبیق دهید.

| نمونه | کاربرد |
|---|---|
| [سبد خرید](سبد%20خرید.sql) | نمایش سطری کالا و متعلقات سبد همراه با قیمت پایه، تخفیف و مبلغ نهایی |

این query برای گزارش و عیب‌یابی است؛ محاسبه و ثبت نهایی مبلغ سفارش را API سمت سرور انجام می‌دهد. [راهنمای سبد](../store/cart.md)

کوئری ردیف‌های ذخیره‌شده را حتی در صورت غیرفعال شدن کالا یا طرح نشان می‌دهد. قیمت مفقود NULL و وضعیت آن missing-price است؛ برای تنوع بدون قیمت، قیمت پایه جایگزین نمی‌شود. مبلغ پس از اعمال تخفیف مانند سرور گرد می‌شود. این گزارش فعال بودن طرح، مجاز بودن متعلقات یا موجودی را تأیید نمی‌کند.
