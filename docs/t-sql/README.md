# نمونه‌های T-SQL

این پوشه queryهای کمکی برای بررسی داده‌های زندهٔ فروشگاه را نگه می‌دارد. نمونه‌ها فقط خواندنی‌اند مگر آن‌که در متن query خلاف آن مشخص شده باشد؛ پیش از اجرا، شناسه‌ها و نام ستون‌ها را با نسخهٔ جاری پایگاه تطبیق دهید.

| نمونه | کاربرد |
|---|---|
| [سبد خرید](سبد%20خرید.sql) | نمایش سطری کالا و متعلقات سبد همراه با قیمت پایه، تخفیف و مبلغ نهایی |

این query برای گزارش و عیب‌یابی است؛ محاسبه و ثبت نهایی مبلغ سفارش را API سمت سرور انجام می‌دهد. [راهنمای سبد](../store/cart.md)

`ProductName` در همهٔ ردیف‌ها نمایش داده می‌شود؛ `TreePathNames` فقط مسیر تنوع است و در نبود مسیر خالی می‌ماند. `AccessoryName` فقط برای متعلقاتی پر است که واقعاً در سبد ذخیره شده‌اند؛ متعلقهٔ تعریف‌شده ولی انتخاب‌نشده ردیف ندارد. ردیف‌های متعلقه مانند `OrderAccessory` بر اساس محصول و طرح فروش گروه‌بندی می‌شوند و تعداد اقلام گروه را جمع می‌کنند؛ `IdCartItem` و `IdProductVariant` برای این ردیف‌ها خالی است. کوئری فقط ردیف‌هایی را می‌آورد که قیمت فعال مطابق محصول و طرح فروش دارند؛ ردیف بدون قیمت فعال به‌دلیل `INNER JOIN` از خروجی حذف می‌شود. مبلغ پیش از تخفیف و مبلغ نهایی از ستون‌های ذخیره‌شده خوانده می‌شوند و به migrationهای ۱۵۲ و ۱۵۳ نیاز دارند. این گزارش فعال بودن طرح، مجاز بودن متعلقات یا موجودی را تأیید نمی‌کند.
