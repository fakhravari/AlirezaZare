# الگوی راهنمای قابلیت

این الگو را در پوشهٔ حوزهٔ مسئول استفاده کنید؛ عنوان یا بخش غیرمرتبط را حذف کنید. نمونهٔ کامل را جایگزین اطلاعات واقعی قابلیت کنید.

```markdown
# نام قابلیت

هدف و محدوده؛ پیوند به قراردادهای مشترک.

## نقاط ورود
- route و Controller:
- منبع داده و قرارداد:
- View و asset:

## رفتار جاری
جریان کار، حالت‌ها و منبع حقیقت؛ demo و دادهٔ عملیاتی را تفکیک کنید.

## تغییر و بررسی
owner واقعی، حالت‌های لازم و فرمان/مرور متناسب.

## محدودیت
فقط محدودیت تأییدشدهٔ فعلی؛ کار آینده را از قابلیت اجراشده جدا کنید.

---
[README بخش](README.md) · [فهرست docs](../README.md)
بازبینی: YYYY-MM-DD
```

پیش از ایجاد فایل [قانون مستندسازی](documentation.md) را بخوانید، README بخش و فهرست اصلی را به‌روز کنید و checker را اجرا کنید.
